# Esquemas NFS-e Nacional

Os XSDs em producao-restrita/ foram obtidos sem alterações do pacote oficial da Produção Restrita, versão 1.01, publicado em 20/10/2026.

Fonte oficial: https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/producao-restrita
Pacote: https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/producao-restrita/esquemas_prod_restrita_20261020.zip

Consulte o portal antes de atualizar o ambiente. Quando o leiaute mudar, substitua o pacote XSD e atualize NFSE_DPS_SCHEMA_PATH para o esquema correspondente.
